# Sondeo topográfico de Roy

Pegar `roy_topography_probe.js` completo en Earth Engine Code Editor y ejecutar una vez.
Los cuatro puntos se consultan juntos. Descargar el enlace **DESCARGAR CSV** de la consola.
Salida: `roy_topography_probe.csv`, hasta 300 filas: 4 puntos × 25 píxeles × 3 fuentes.

Estado: preparado localmente; aún no ejecutado en Earth Engine.
No modifica TIFF, HDF5, admisiones, particiones ni configuraciones de entrenamiento.
No obtiene ni transmite máscaras o credenciales.

Consultar el [protocolo y sus límites](../../../docs/datasets/roy_topography_probe.md).
